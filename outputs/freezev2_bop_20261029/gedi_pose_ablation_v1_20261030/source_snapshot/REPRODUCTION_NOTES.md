# Source mappings, assumptions and deviations

This experiment extends the completed independent FreeZeV2 base implementation with one explicit robustness policy and one separate CAD input-size ablation. The original benchmark remains unchanged. The primary paper and full initial source mapping remain in experiments/freezev2_bop_20261029/REPRODUCTION_NOTES.md; the immutable executed baseline is outputs/freezev2_bop_20261029/classic_core_base_v2/source_snapshot. This document records the new differences, not a claim of published-performance reproduction.

Public source references for the476 input convention: [features.py at the pinned revision](https://github.com/tfwang08/FreezeV2-Re/blob/12f82a2f8afd435466a87cf2dafce404087aeb3f/freezev2/features.py) and the actual run_bop.py call path, as inspected in the preceding public-source audit. No public source code is copied into these independent helpers. Existing third-party dependency licenses and original attribution remain in the original experiment's provenance records.

Measured scores belong only to the seven-target failure-heavy cohort. A successful descriptor or valid pose is not proof of correct pose. Only the separate official receipts establish the reported cohort pose AR. These runs do not measure segmentation AP, CAD classification accuracy, a complete T-LESS score, a seven-dataset aggregate, or paper-performance parity. Parameters are not selected by test GT and no configuration sweep is authorized here.
