## Current execution scope

- `prepare_assets.py` verifies and aliases the existing images, native CADs,
  calibration, official targets, predicted masks and checkpoints. Its inference
  view excludes GT pose/info annotations. JPEG/TIFF image bytes are preserved;
  PIL format decoding is checked despite the public code's `.png` path suffix.
- `reference_gate.py` executes the original public `run_bop.py evaluate-reference`
  on untouched author CSVs with the existing official BOP evaluator. It audits
  source/input hashes and retains the full target denominator.
- An author-prediction score match establishes evaluator agreement only. Those
  CSVs are **FreeZeV2.1/Accurate**, not predictions generated by this study and not
  evidence that a base configuration reaches their performance.
- Own LM-O inference and official evaluation are complete in `own_inference_v1`; the other six datasets are stopped by the user comparison gate. See the verified-result update below. The public code requires an explicit
  DINO layer, visibility depth tolerance, and pose NMS distance. Its README gives
  no complete validated inference preset. The raw CAD sample count is also
  unresolved: 5,000 is a documented smoke-test count before visibility filtering,
  while the paper describes 5,000 final retained points. No official values are
  inferred from test GT or the authors' saved predictions.

## Original CAD-render smoke check

`onboard_original.py` calls the public original onboarding APIs without replacing
sampling, camera fitting or rendering. It reuses cached pure-Python Trimesh 4.4.1
from `outputs/cache/fabrica_native_20261027/python/trimesh` through an isolated
package alias, and the existing evaluation venv's VisPy. It does not install
packages or expose that entire cache's Python tree.

After full asset preparation is complete, this fixed T-LESS object 1 smoke check
uses 5,000 **raw** samples, 162 original 480 px renders, native millimetres and the
returned fitted cameras. It does not establish 5,000 visibility-retained feature
points, descriptors, inference or pose accuracy:

