## Completed and measured

- Reused and verified all seven existing BOP input sets: 3,871 images, 13,635 official
  object-image targets, 19,048 requested instances and 125 native CADs. Existing
  model checkpoints and masks were reused. No dataset/model/checkpoint copies,
  moves or downloads were made. The inference alias view has zero GT pose links.
  This CPU preparation took 1,524.087 seconds; it is not inference time.
- Original public offline tests: 78 passed, 2 optional onboarding tests skipped in
  that invocation's environment. Combined new helper tests: 81 passed. These are
  correctness/readiness checks, not benchmark accuracy.
- Ran the original public LM-O `evaluate-reference` command using the untouched
  authors' FreeZeV2.1/Accurate CSV and pinned official BOP Toolkit. The full 1,445
  target denominator was retained. Measured AR 0.7713587082, VSD 0.6233494810,
  MSSD 0.8294117647 and MSPD 0.8613148789. All agree with the public three-decimal
  reference values within the original 0.0005 tolerance. Evaluator wall time was
  96.538 seconds. No own inference generated these predictions.
- Executed the original onboarding API for T-LESS object 1: 5,000 explicit raw
  samples, 162 RGB/depth templates at 480×480, original PLY and fitted returned
  cameras in native millimetres. It took 13.233 seconds. All saved arrays and RGBs
  were checked and hashed. Nine fixed rendered views were visually reviewed;
  the CAD is centered and in frame, with thin dark contour/seam-like lines visible
  in the end views. This is a geometry smoke check, not 5,000 final feature points
  or a pose-performance result.

## Not completed or established

No own pose predictions or benchmark pose metrics were generated by this study.
The public source is executable code, but it has no complete validated inference
preset, including in its inspected 225-commit history. DINO layer and depth
visibility tolerance are mandatory explicit values, as is the global translation
NMS threshold in millimetres. Its documented 5,000 raw samples do not establish the
paper's 5,000 visibility-retained points. Layer 30 is explicitly a smoke-test
candidate. These missing values must not be presented as known author settings
or selected by BOP test-ground-truth performance.

A future declared third-party configuration can be executed, but its assumptions
and newly generated performance must be reported separately from author-code
replication and the saved Accurate prediction score. No full public-code pose
benchmark has been launched using guessed settings. The original independent
baseline and GeDi/CAD-resolution ablation remain unchanged.

HB/ITODD test GT remains private; this study makes no local metrics or seven-set
aggregate claim and has made no automatic benchmark submission. The README gives
exact local commands for preparation, cache-checked geometry reuse, offline tests
and the five public author-reference evaluations. The other four public reference
CSV evaluations have not been run in this study; HB/ITODD reference metrics cannot
be independently scored locally.

Machine-readable status is `results_summary.json` in the output folder. Actual
receipts, hashes, commands and the contact sheet remain with that output. No
production/NIST/grasp code, global/shared environment, historical result, Git index,
remote repository or physical robot was changed.
