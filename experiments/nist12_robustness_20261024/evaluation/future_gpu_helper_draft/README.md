# Generic GPU fit helper: isolated draft

No running code imports this folder. The helper has no scientific-library import and tests supply entirely fake geometry, proxy, tree, runtime and writer dependencies. No real query, fit, GPU, CAD, model or accuracy annotation is used. This prepares a later decision; it does not authorize integration or another GPU job.

`run_gpu_fit` calls the supplied unchanged `run_depth.fit_job` once. It intercepts only the process-local fit entry and exact summary writer, forwarding their original result/value objects. Wrapping at fit entry covers cached CADs whose factory will not run again. A fresh reviewed `CertifiedQueryTree` wraps the bare original tree; the per-job runtime closes and the bare tree is restored before the original bank/summary path can commit. Full hypothesis count is derived from the supplied CAD supports and original yaw set, with no pose filtering, point reduction, score replacement or cache-key change.

The worker uses GPU threshold131072, original CPU fallback4 and device cap128MiB. It is deliberately for dense/very-dense jobs with more than131072 observed voxels, so each successful job requires fresh positive GPU and certified-row counts. Ordinary banks below that threshold belong to the CPU path. Global resource overrides and process-local functions are restored in `finally`.

`WorkerState` is created inside the future spawn child before CAD/context preparation. Its measured lifetime RSS baseline is reused for every job, alongside owner PID/thread, a busy flag, attempted keys and poisoned status. There is no automatic retry. A failure poisons the worker; caller must drain/verify exit and inspect normal cache evidence before any explicit resume. A repeated key cannot open another runtime or write twice. A callback/source check failure after a valid original commit is reported as needing review, never converted to an unavailable score.

Two mandatory hooks remain separate integration gates:

- `admit(job, lifetime_baseline)` returns a freshly measured, JSON-safe dictionary containing stage, observed voxels, **explicitly approved** host increment cap, sample UTC, actual current worker RSS and actual physical host availability, all byte counts as integers. The helper admits only if at least2GiB reserve remains after the cap's remaining growth above the current lifetime baseline. It does not reset the baseline per job. No budget for greater-than2M clouds is established here; approving one requires representative capacity evidence.
- `guard(job, phase, admission)` must verify the frozen numeric/source/input/build/proof pins, exact job/observation/key provenance, central dispatcher lease, serial cohort/pilot handoff and approved stage resource policy. It runs before `fit_job`, at fit entry/completion, before atomic summary commit and afterward. The helper independently blocks an existing prediction lock and existing summary/archive/part evidence. A final high-water/FP check covers dimensions, compression and archive creation before the original atomic summary writer.

Original native unavailable projections remain legitimate full-bank results; accelerator, resource, source or cleanup failures raise instead. An unreferenced archive can remain after a pre-summary failure and is hashed in the technical receipt. Existing audit directories are never overwritten. Fresh per-job counters and technical completion records avoid borrowing success from a preceding job.

The caller owns distinct spawn executor configuration, one GPU slot, whole-worker shutdown/control-interrupt policy, physical reserve monitoring and complete provenance/lock inventory. The helper also marks a worker poisoned on `KeyboardInterrupt`/`SystemExit`, restores/cleans up and re-raises the control exception; it does not turn cancellation into success. Forced process termination and executor shutdown still require the caller's separate policy. Source checking is intentionally a mandatory injected hook rather than a permissive default. A future adapter must pin this helper and all dependencies before use and verify every receipt before final queue completion. Current42 pilot pins remain unchanged.
